2020 baseline: forest on the cut-off date, its type, rubber, TMF's 2020 class, land or water, earlier Hansen loss, protected area
Clearing after 2020: the first year each source sees it (3 bits: 0 none, 1–7 = 2021–2027), TMF degradation, RADD confidence and coverage
Near-real-time alerts: the latest optical alert (GLAD-L or DIST-ALERT) and its confidence, for the months after the yearly data
Worked out at build time: what Sentinel-2 shows after the clearing, and whether the pixel sits next to a confirmed clearing, so every query stays per pixel
Example: 8,405,040, the most common value on the Jambi map = land (bits 23–24 = 1) + TMF 2020 class 3, deforested land (bits 4–6) + Hansen loss in 2001–2020 (bit 14), every other field 0. The land was cleared before the cut-off, so it is not deforestation under the EUDR.
