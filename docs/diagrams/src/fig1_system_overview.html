From about 20 satellite layers to a plot verdict

Step 1 compacts the layers once per data release. Step 2 stores them in Neon, where every batch of plots is checked in one query.

Inputs
Satellite layers, 2000–2026
  • JRC forest cover 2020 (10 m)
  • JRC forest types 2020
  • JRC TMF yearly change
  • Hansen tree-cover loss
  • RADD radar alerts
  • GLAD-L, DIST-ALERT alerts
  • UMD primary forest 2001
  • Sentinel-2 land cover
  • Rubber map 2020
  • WDPA protected areas
21 layers, different grids and resolutions: 234.5 MB for one 0.5° box
Step 1 · Compaction
eudr_layers.py
  • one 10 m grid (1/12,000°)
  • only the facts the rule reads
  • time as event years, not yearly maps
  • the EUDR rule, per pixel
evidence.tifevery decision fact per pixel, bit-packed
outcome.tifone of 5 colours per pixel
--verify re-judges every plot from the original layers
Step 2 · Storage
Neon PostgreSQL + PostGIS
pipeline.py or the ingest window uploads a map in one transaction

evidence_pages
stencil_pages
class_polys, square_labels
protected_areas
plots, results
public.maps lists every map
