# Several Maps in Neon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Store several named EUDR maps in Neon, one schema each. The PyQt app can upload, switch between and delete them.

**Architecture:**
- **Storage.** Each map's six tables live in schema `map_<name>`, and `public.maps` lists the maps.
- **Backend.** Every table is named through `Grid.table()`. The schema travels on the `Grid` that all code already passes around, so queries and round trips are otherwise unchanged.
- **New `backend/database/maps.py`.** It lists, uploads, describes, deletes and migrates maps. An upload builds both approaches in one transaction.
- **App.** A Map dropdown, an Upload dialog and a Delete dialog (`frontend/maps_ui.py`), built on the existing worker and job system.

**Tech Stack:** Python 3.10+, psycopg 3, PostgreSQL + PostGIS on Neon (PgBouncer pooling), rasterio, numpy, PyQt5 5.15 + QtWebEngine (Leaflet 1.9.4, ES2019).

**Spec:** `docs/superpowers/specs/2026-10-15-multi-map-design.md`

## Global Constraints

- **Language versions:** code stays Python 3.10-compatible. Map JavaScript stays ES2019, because Qt WebEngine 5.15 is Chromium 83.
- **Dependencies:** none beyond `frontend/requirements.txt` and `backend/requirements.txt`. pyflakes is for lint only.
- **Neon pooling:** Neon uses PgBouncer in transaction mode.
  - Keep `prepare_threshold=None`.
  - Use `SET LOCAL` only.
  - End every transaction.
  - Batch farms into a few queries.
- **Secrets:** never print or log `DATABASE_URL` or anything from `.env`.
- **Customer data:** real TIFFs and GeoJSONs are customer data. Tests make made-up TIFFs in temporary folders, and the backend prints use "x", not "×" or "…" (the Windows console is cp1252).
- **The user's real map:** `jambi-v1` is touched only by `maps.py migrate` (Task 5), after a read-only pre-check.
- **Wording:** plain English and British spelling. Error messages say how to fix the problem.
- **Map names:** 1–40 printable characters, with at least one letter or digit. The schema is `map_` + the lowercase name, with runs of other characters replaced by `_`.
- **Upload limit:** 100,000,000 pixels.
- **No git:** this folder is not a git repository and no commits were asked for. Each task ends with a test checkpoint instead of a commit.
- **Commands** run from `HackNHire\` in Git Bash:
  - tests: `frontend/.venv/Scripts/python -m unittest discover -s frontend/tests -t frontend`
  - lint: `frontend/.venv/Scripts/python -m pyflakes frontend/*.py frontend/tests/*.py backend/database backend/compare`
  - backend command line: `backend/venv/Scripts/python backend/database/<script>.py`

"""helpers.py - shared test doubles: a scripted fake database connection, made-up TIFFs, and a

from collections import defaultdict
from types import SimpleNamespace

import rasterio
from PyQt5.QtWidgets import QAction, QMainWindow, QToolBar
from rasterio.transform import from_origin


class Script:
    """A fake psycopg connection. Each query is answered by the first (fragment, rows) whose fragment
    appears in the SQL or in its parameters; everything executed is kept in .sql and .params."""

    def __init__(self, answers=()):
        self.answers = list(answers)
        self.sql, self.params = [], []
        self.commits = self.rollbacks = 0
        self.autocommit = False
        self.closed = False

    def cursor(self):
        return ScriptCursor(self)

    def execute(self, sql, params=None):
        cur = ScriptCursor(self)
        cur.execute(sql, params)
        return cur

    def commit(self):
        self.commits += 1

    def rollback(self):
        self.rollbacks += 1

    def close(self):
        self.closed = True

    def answer(self, sql, params):
        text = f"{sql} | {params!r}"
        for fragment, rows in self.answers:
            if fragment in text:
                return list(rows)
        return []


class ScriptCursor:
    def __init__(self, conn):
        self.conn, self.rows = conn, []

    def __enter__(self):
        return self

    def __exit__(self, *exc):
        return False

    def execute(self, sql, params=None):
        self.conn.sql.append(sql)
        self.conn.params.append(params)
        self.rows = self.conn.answer(sql, params)

    def executemany(self, sql, rows):
        for params in rows:
            self.execute(sql, params)

    def fetchone(self):
        return self.rows[0] if self.rows else None

    def fetchall(self):
        return list(self.rows)


def write_tiff(path, data, x0=110.0, y0=-7.0, pixel=1 / 12000, crs="EPSG:4326"):
    """Save a made-up single-band GeoTIFF of class codes (never a real map) and return its path."""
    with rasterio.open(path, "w", driver="GTiff", width=data.shape[1], height=data.shape[0], count=1,
                       dtype="uint8", crs=crs, transform=from_origin(x0, y0, pixel, pixel)) as dst:
        dst.write(data, 1)
    return path

    def __init__(self):
        super().__init__()
        self.draw_act = QAction("Draw", self)
        self.toolbar = QToolBar()
        self.toolbar.addAction(self.draw_act)
        self.addToolBar(self.toolbar)
        self.eudr = FakeEudr()
        self.compare = SimpleNamespace(job=None)
        self.cancelled = 0
        self.worker = SimpleNamespace(cancel=self._cancel)
        self.map_info = None
        self.geojson = {"type": "FeatureCollection", "features": []}
        self.jobs, self.js_calls, self.map_calls, self.events = [], [], [], []
        self.map = SimpleNamespace(call=lambda fn, *args: self.map_calls.append((fn,) + args))
        self.listeners = defaultdict(list)

    def _cancel(self):
        self.cancelled += 1

    def action(self, text, icon=None, shortcuts=(), slot=None):
        act = QAction(text, self)
        if slot:
            act.triggered.connect(slot)
        return act

    def insert_tools(self, anchor, items):
        for item in items:
            if item is None:
                self.toolbar.insertSeparator(anchor)
            elif isinstance(item, QAction):
                self.toolbar.insertAction(anchor, item)
            else:
                self.toolbar.insertWidget(anchor, item)

    def listen(self, event, callback):
        self.listeners[event].append(callback)

    def emit(self, event, *args):
        self.events.append((event,) + args)
        for callback in list(self.listeners[event]):
            callback(*args)

    def run_job(self, kind, method, *args, **kwargs):
        self.jobs.append((kind, method, args, kwargs))
        return len(self.jobs)

    def js(self, code):
        self.js_calls.append(code)

# Several maps. Each map's tables live in its own schema (a folder of tables), e.g.
# map_jambi_v1, and public.maps lists the maps. Every query names its tables with the schema

def map_schema(name: str) -> str:
    """A map's name -> the schema its tables live in: 'Jambi v1' -> 'map_jambi_v1'.
    Stops with a message saying what to change if the name can't be used."""
    name = (name or "").strip()
    if not name:
        sys.exit("A map needs a name, e.g. jambi-v1.")
    if len(name) > MAP_NAME_MAX:
        sys.exit(f"A map name can be at most {MAP_NAME_MAX} characters; this one has {len(name)}.")
    if not name.isprintable():
        sys.exit("A map name can't contain tabs, line breaks or other control characters.")
    slug = re.sub(r"[^a-z0-9]+", "_", name.lower()).strip("_")
    if not slug:
        sys.exit(f"'{name}' can't be used as a map name: include at least one letter (a-z) or digit.")
    return "map_" + slug


def default_map_name(tif_path: str) -> str:
    """The name a map gets when none is given: the TIFF's file name without .tif."""
    return os.path.splitext(os.path.basename(tif_path))[0]

    pixel_h        DOUBLE PRECISION NOT NULL,  -- pixel height (map units)

def find_map(conn: psycopg.Connection, name: str | None = None) -> tuple[str, str]:
    """(name, schema) of a stored map. Without a name: the only map stored. A name matches a map's
    exact name, or else its schema ('Jambi V1' finds 'jambi-v1'). Stops with a message saying what
    to do if there is no such map, or several maps and no name."""
    if not table_exists(conn, "public.maps"):
        sys.exit(OLD_LAYOUT_MESSAGE if table_exists(conn, "public.grid_info") else NO_MAP_MESSAGE)
    with conn.cursor() as cur:
        cur.execute("SELECT name, schema_name FROM public.maps ORDER BY lower(name)")
        stored = [tuple(row) for row in cur.fetchall()]
    if not stored:
        sys.exit(NO_MAP_MESSAGE)
    names = ", ".join(n for n, _ in stored)
    if name is None:
        if len(stored) > 1:
            sys.exit(f"Several maps are stored ({names}). Choose one with --map NAME.")
        found = stored[0]

class Progress:
    """Prints progress every 10% - but only for jobs slow enough to need it. With report, also
    calls report(label, done, total) on every step (the app's progress bar); report may raise
    to stop the job."""

    def __init__(self, total: int, label: str, report=None):
        self.total, self.label, self.done, self.start = total, label, 0, time.perf_counter()
        self.next_report = 0.1
        self.report = report

    def step(self) -> None:
        self.done += 1
        if self.report is not None:
            self.report(self.label, self.done, self.total)
        elapsed = time.perf_counter() - self.start
        if self.done / self.total >= self.next_report:
            if elapsed > 2 or (self.done == self.total and elapsed > 0.5):
                print(f"  {self.label}: {100 * self.done / self.total:5.1f}% ({elapsed:.1f}s)", flush=True)
            while self.next_report <= self.done / self.total:
                self.next_report += 0.1


def scan_map(src, grid: Grid, report=None) -> tuple[np.ndarray, str]:
    """One pass over the TIFF: how many pixels of each colour, and a fingerprint that
    identifies this exact map (so programs can tell if the database holds a different one)."""
    counts = np.zeros(len(COLOURS), np.int64)
    fingerprint = Fingerprint(grid)
    progress = Progress(math.ceil(src.height / PAGE), "reading the map", report)
    for _, strip in iter_strips(src):
        counts += np.bincount(strip.ravel(), minlength=len(COLOURS))[:len(COLOURS)]
        fingerprint.add(strip)
        progress.step()
    return counts, fingerprint.hexdigest()

    schema (created if needed) and in the list of maps. Refuses a name too close to another map's,
    and a TIFF that is already stored under another name. If this map held a DIFFERENT TIFF
    before, the other approach's tables are removed, so a map never mixes two TIFFs."""
    name = map_name.strip()
    schema = map_schema(name)
    grid = Grid.from_dataset(src, name)
    print(f"Map '{name}': {grid.width} x {grid.height} pixels, EPSG:{grid.srid}, "
          f"pixel {grid.pixel_w:g} x {grid.pixel_h:g}, stored in schema {schema}")

    default = int(np.argmax(counts))
    grid = dataclasses.replace(grid, default_class=default, fingerprint=fingerprint, schema=schema)

"""
maps.py - several maps in one Neon database, each in its own schema (a folder of tables).

    public.maps     the list of maps: name, schema, source TIFF, fingerprint, size
    map_<name>      grid_info, stencil_pages, class_polys, square_labels, plots, plot_results

A map's schema comes from its name: 'Jambi v1' -> map_jambi_v1 (common.map_schema). Every query
names its tables with the schema (grid.table(...)), so maps never mix.

Commands (run from the project folder; TIFFs are looked up in data/tiff/, or give a full path)
    python database/maps.py list
    python database/maps.py upload my_map.tif [--name "Jambi v1"]   # both approaches at once
    python database/maps.py delete "Jambi v1" --yes                  # can't be undone
    python database/maps.py migrate [--name jambi-v1]                # a map stored the old way

upload is ONE transaction: if anything fails, or you press Ctrl+C, nothing is left behind.
"""

import argparse
import sys
import time

import rasterio

import common
import polygon_approach
import stencil_approach

MAX_PIXELS = 100_000_000   # the app keeps the whole map in memory: 1 byte per pixel
MAP_TABLES = ["grid_info", "stencil_pages", "class_polys", "square_labels", "plots", "plot_results"]
UPLOAD_STEPS = 7           # stencils: read, pack, index; outlines: read, trace, index; tidy up


def size_problem(width: int, height: int) -> str:
    """Why a map is too big for the app ("" if it isn't)."""
    if width * height <= MAX_PIXELS:
        return ""
    return (f"This map is {width:,} x {height:,} pixels. The app keeps the whole map in memory, so it "
            f"supports up to {MAX_PIXELS // 1_000_000} million pixels (e.g. 10,000 x 10,000). "
            "Crop it into smaller areas first.")


def list_maps(conn) -> list[dict]:
    """Every stored map, by name: where it lives, its TIFF, its size and which approaches it has."""
    if not common.table_exists(conn, "public.maps"):
        if common.table_exists(conn, "public.grid_info"):
            sys.exit(common.OLD_LAYOUT_MESSAGE)
        return []
    with conn.cursor() as cur:
        cur.execute("""
            SELECT m.name, m.schema_name, m.source_file, m.width, m.height, m.added_at,
                   to_regclass(m.schema_name || '.stencil_pages') IS NOT NULL,
                   to_regclass(m.schema_name || '.class_polys') IS NOT NULL
                       AND to_regclass(m.schema_name || '.square_labels') IS NOT NULL
            FROM public.maps m
            WHERE to_regnamespace(m.schema_name) IS NOT NULL
            ORDER BY lower(m.name)""")
        rows = cur.fetchall()
    return [{"name": name, "schema": schema, "source_file": source, "width": width, "height": height,
             "added_at": added.isoformat() if added else None, "stencils": bool(stencils),
             "outlines": bool(outlines)}
            for name, schema, source, width, height, added, stencils, outlines in rows]


def upload(conn, tif: str, name: str, report=None) -> common.Grid:
    """A new map with BOTH approaches, in one transaction: if anything fails or is cancelled
    (report may raise), everything is rolled back and the database is as it was. Then the new
    tables are packed (VACUUM ANALYZE), which can't run inside a transaction."""
    name = (name or "").strip()
    common.map_schema(name)  # stops here if the name can't be used
    has_catalogue = common.table_exists(conn, "public.maps")
    if not has_catalogue and common.table_exists(conn, "public.grid_info"):
        sys.exit(common.OLD_LAYOUT_MESSAGE)
    if has_catalogue:
        with conn.cursor() as cur:
            cur.execute("SELECT 1 FROM public.maps WHERE name = %s", (name,))
            if cur.fetchone():
                sys.exit(f"There's already a map called '{name}'. Choose another name, "
                         "or delete that map first.")
    with rasterio.open(tif) as src:
        problem = size_problem(src.width, src.height)
    if problem:
        sys.exit(problem)
    start = time.perf_counter()
    try:
        stencil_approach.build(conn, tif, name, report, tidy=False)
        grid = polygon_approach.build(conn, tif, name, report, tidy=False)
        conn.commit()
    except BaseException:
        conn.rollback()
        raise
    tables = [grid.table(t) for t in ("stencil_pages", "class_polys", "square_labels")]
    for i, table in enumerate(tables):
        if report is not None:
            report("tidying up", i, len(tables))
        common.tidy_up(conn, table)
    if report is not None:
        report("tidying up", len(tables), len(tables))
    print(f"Uploaded '{name}' (both approaches) in {time.perf_counter() - start:.1f} s")
    common.print_storage(conn, [grid.table(t) for t in MAP_TABLES])
    return grid


def describe(conn, name: str) -> dict:
    """What a map uses in the database, and how many saved verdicts would go with it."""
    map_name, schema = common.find_map(conn, name)
    with conn.cursor() as cur:
        cur.execute("""
            SELECT coalesce(sum(pg_total_relation_size(c.oid)), 0)
            FROM pg_class c JOIN pg_namespace n ON n.oid = c.relnamespace
            WHERE n.nspname = %s AND c.relkind = 'r'""", (schema,))
        size = int(cur.fetchone()[0])
        saved = 0
        if common.table_exists(conn, f"{schema}.plot_results"):
            cur.execute(f"SELECT count(*) FROM {schema}.plot_results")
            saved = int(cur.fetchone()[0])
        cur.execute("SELECT source_file, width, height FROM public.maps WHERE name = %s", (map_name,))
        source_file, width, height = cur.fetchone()
    return {"name": map_name, "schema": schema, "bytes": size, "saved_results": saved,
            "source_file": source_file, "width": width, "height": height}


def delete(conn, name: str) -> dict:
    """Remove a map: its schema (every table in it) and its row in public.maps, in one transaction.
    Needs the map's exact name."""
    map_name, schema = common.find_map(conn, name)
    if map_name != name.strip():
        sys.exit(f"To delete a map, give its exact name: '{map_name}'.")
    if not common.SCHEMA_RE.match(schema):  # never drop anything that isn't a map's own schema
        sys.exit(f"Refusing to delete schema '{schema}': it isn't a map's schema (map_...).")
    with conn.cursor() as cur:
        cur.execute(f"DROP SCHEMA IF EXISTS {schema} CASCADE")
        cur.execute("DELETE FROM public.maps WHERE name = %s", (map_name,))
    conn.commit()
    return {"name": map_name, "schema": schema}


def migrate(conn, name: str | None = None) -> str:
    """Move a map stored the old way (its tables in the public schema) into a schema of its own,
    and list it in public.maps. One transaction; nothing is copied, so it takes about a second.
    To undo: ALTER TABLE <schema>.<table> SET SCHEMA public for each table, then delete its row."""
    if not common.table_exists(conn, "public.grid_info"):
        sys.exit("Nothing to move: no map is stored the old way (there is no public.grid_info).")
    with conn.cursor() as cur:
        cur.execute("SELECT map_version, fingerprint, source_file, width, height FROM public.grid_info")
        rows = cur.fetchall()
    if len(rows) != 1:
        sys.exit(f"public.grid_info should describe one map but has {len(rows)} rows, "
                 "so it can't be moved automatically.")
    old_name, fingerprint, source_file, width, height = rows[0]
    name = (name or old_name or "").strip()
    schema = common.map_schema(name)
    with conn.cursor() as cur:
        cur.execute(common.CATALOGUE_SQL)
        cur.execute("SELECT 1 FROM public.maps WHERE name = %s OR schema_name = %s", (name, schema))
        if cur.fetchone():
            sys.exit(f"A map called '{name}' (schema {schema}) already exists. Choose another --name.")
        cur.execute("SELECT to_regnamespace(%s) IS NOT NULL", (schema,))
        if cur.fetchone()[0]:
            sys.exit(f"The schema {schema} already exists. Choose another --name.")
        cur.execute(f"CREATE SCHEMA {schema}")
        moved = []
        for table in MAP_TABLES:
            if common.table_exists(conn, f"public.{table}"):
                cur.execute(f"ALTER TABLE public.{table} SET SCHEMA {schema}")
                moved.append(table)
        if name != old_name:
            cur.execute(f"UPDATE {schema}.grid_info SET map_version = %s", (name,))
            if "plot_results" in moved:
                cur.execute(f"UPDATE {schema}.plot_results SET map_version = %s WHERE map_version = %s",
                            (name, old_name))
        cur.execute("INSERT INTO public.maps (name, schema_name, source_file, fingerprint, width, height) "
                    "VALUES (%s,%s,%s,%s,%s,%s)", (name, schema, source_file, fingerprint, width, height))
    conn.commit()
    print(f"Moved the map '{name}' into schema {schema}: {', '.join(moved)}")
    return name


def print_list(stored: list[dict]) -> None:
    if not stored:
        print("No maps stored yet. Upload one with:\n"
              "  python database/maps.py upload my_map.tif --name NAME")
        return
    for m in stored:
        built = " + ".join(a for a, ok in (("stencils", m["stencils"]), ("outlines", m["outlines"])) if ok)
        size = f"{m['width'] or 0:,} x {m['height'] or 0:,} px"
        print(f"  {m['name']:<24} {m['schema']:<26} {size:>18}  {m['source_file'] or '':<20} "
              f"{built or 'nothing built'}")

def copy_to_tiff_folder(path):
    """Keep a copy of an uploaded TIFF in backend/data/tiff, where the app looks for the original
    TIFF to compare with. Never overwrites a file. Returns what happened, for the status bar."""
    name = os.path.basename(path)
    folder = os.path.abspath(common.TIFF_DIR)
    if os.path.dirname(os.path.abspath(path)) == folder:
        return f"{name} is already in backend/data/tiff."
    target = os.path.join(folder, name)
    if os.path.exists(target):
        return f"backend/data/tiff already has a {name}, so no copy was made."
    os.makedirs(folder, exist_ok=True)
    shutil.copy2(path, target)
    return f"Copied {name} to backend/data/tiff."


class UploadProgress:
    """Turns the backend's progress reports (label, done, total) into one bar for the whole upload:
    each new label is the next of maps.UPLOAD_STEPS steps. Raises Cancelled once cancel is set."""

    PART = {1: "Stencils", 2: "Stencils", 3: "Stencils", 4: "Outlines", 5: "Outlines", 6: "Outlines"}

    def __init__(self, progress, cancel=None, steps=maps.UPLOAD_STEPS):
        self.progress, self.cancel, self.steps = progress, cancel, steps
        self.step, self.label = 0, None

    def __call__(self, label, done, total):
        if self.cancel is not None and self.cancel.is_set():
            raise Cancelled()
        if label != self.label:
            self.step, self.label = min(self.step + 1, self.steps), label

    def _run(self, work, write=False, retry=True):
        """Run work(conn) and end the transaction (commit if write, else rollback). A dropped
        connection (psycopg.OperationalError) gets one reconnect and one retry - unless
        retry=False: an upload is too long to start again by itself."""
        for attempt in (1, 2):
            if self.conn is None or self.conn.closed:
                self.conn = self._connect()
            try:
                result = work(self.conn)
                if write:
                    self.conn.commit()
                else:

                return result
            except psycopg.OperationalError:
                self._close()
                if attempt == 2 or not retry:
                    raise
                self.on_status("Reconnecting to Neon…")
            except BaseException:
                try:
                    self.conn.rollback()
                except Exception:  # noqa: BLE001 - connection broken: start fresh next time
                    self._close()
                raise

        """A message over the map. With an action, a button runs it ('Retry' unless named)."""
        self.banner_action = action or (lambda: None)
        if action is not None and button is None:
            button = "Retry"
        self.banner.show_message(text, error=error, button=button if action is not None else None)
        self.w.map_area.relayout()

    def load(self, name):
        """Load a stored map from Neon (on the worker thread), then show it."""
        self.name = name
        self.neon_label.setText("Neon: connecting…")
        self.show_banner(f"Loading the map '{name}' from Neon…")
        self.w.run_job("open_map", "open_map", name, done=self.loaded,
                       failed=lambda message: self.failed(name, message), coalesce=True)

    def loaded(self, info):
        if info["map_version"] != self.name:  # a slower load of a map chosen earlier: ignore it
            return
        service = self.w.worker.service
        self.w.tile_handler.set_map(service.grid, service.classes, service.to_map)
        self.info = info
        self.w.map.call("setMapInfo", info)
        self.legend.set_info(info)
        self.banner.hide()
        self.w.map_area.relayout()
        self.neon_label.setText(f"Neon: connected · {info['map_version']} · "
                                f"{info['width']:,} × {info['height']:,} px")
        self.w.map_info = info
        self.w.emit("map_loaded", info)

    def failed(self, name, message):
        if name != self.name:  # an earlier choice failing late: the map chosen since is loading
            return True
        self.neon_label.setText("Neon: map not loaded")
        self.show_banner(f"Could not load the map '{name}' from Neon. {message}", error=True,
                         action=lambda: self.load(name))
        return True  # shown over the map, with a Retry button

    def clear(self, text, button=None, action=None):
        """Nothing to show: no maps stored yet, or the map shown was deleted."""
        self.info = self.name = None
        self.w.map_info = None
        self.w.tile_handler.set_map(None, None)

"""maps_ui.py - several maps in Neon: the Map dropdown, and Maps ▸ Upload map… / Delete map….

Each map lives in its own schema in Neon (backend/database/maps.py). At start-up the maps are
listed and one is shown: the --map flag, else the last one used, else the first. Choosing another
map loads it the same way. Each map keeps the farms drawn on it while the app is open, so switching
away and back brings them back; check results belong to one map, so they are cleared.

Uploading and deleting are the app's only writes to the map tables, and both ask first.
"""

import os

import rasterio
from PyQt5.QtCore import QSettings, Qt
from PyQt5.QtWidgets import (QCheckBox, QComboBox, QDialog, QDialogButtonBox, QFileDialog, QFormLayout,
                             QHBoxLayout, QLabel, QLineEdit, QMenu, QProgressBar, QPushButton,
                             QToolButton, QVBoxLayout)
from rasterio.errors import RasterioError

from backend import common, maps

NEON_FULL_HINT = "Neon's free plan holds 0.5 GB: delete a map you no longer need, then try again."


# ----- plain helpers (tested without a window) -----
def schema_or_problem(name):
    """(schema, "") for a usable map name, or (None, why it can't be used)."""
    try:
        return common.map_schema(name), ""
    except SystemExit as exc:
        return None, str(exc.code)


def name_problem(name, existing):
    """Why a new map can't have this name ("" if it can). existing: [(name, schema)] of stored maps."""
    name = (name or "").strip()
    schema, problem = schema_or_problem(name)
    if problem:
        return problem
    for other, other_schema in existing:
        if other == name:
            return f"There's already a map called '{other}'. Choose another name, or delete that map first."
        if other_schema == schema:
            return f"'{name}' is too close to '{other}': both would be stored as {schema}. Choose another name."
    return ""


def tiff_summary(path):
    """(what the TIFF is, what's wrong with it) for the upload dialog."""
    if not path:
        return "", "Choose a TIFF file."
    if not os.path.isfile(path):
        return "", f"Can't find the file {path}."
    try:
        with rasterio.open(path) as src:
            grid = common.Grid.from_dataset(src, "upload")
    except SystemExit as exc:  # the backend's own checks: north-up, an EPSG code, ...
        return "", str(exc.code)
    except RasterioError as exc:
        return "", f"This file can't be read as a GeoTIFF ({exc})."
    text = (f"{grid.width:,} × {grid.height:,} px · EPSG:{grid.srid} · "
            f"{grid.width * grid.height / 1e6:,.1f} million pixels")
    return text, maps.size_problem(grid.width, grid.height)


def choose_map(names, *preferred):
    """The first preferred name that is stored, else the first map; None if there are no maps."""
    for name in preferred:
        if name and name in names:
            return name
    return names[0] if names else None


def map_label(info):
    """A map's text in the dropdown: its name, plus a note if an approach is missing."""
    missing = [a for a, built in (("stencils", info["stencils"]), ("outlines", info["outlines"])) if not built]
    return info["name"] + (f"  (no {' or '.join(missing)})" if missing else "")


def map_tooltip(info):
    size = f"{info['width']:,} × {info['height']:,} px" if info.get("width") else ""
    parts = [info.get("source_file") or "", size, f"stored as {info['schema']}"]
    return " · ".join(p for p in parts if p)


def describe_text(info):
    """The delete dialog's line about what will go."""
    saved = info["saved_results"]
    text = f"Uses {info['bytes'] / 1e6:.1f} MB in Neon · {saved:,} saved result{'' if saved == 1 else 's'}"
    return text + (f" · from {info['source_file']}" if info.get("source_file") else "")


def confirmed(typed, name):
    """Delete is allowed only once the map's exact name has been typed."""
    return bool(name) and typed.strip() == name


def upload_error_text(message):
    """What the upload dialog says when an upload stopped (nothing is ever half-saved)."""
    if message == "Cancelled.":
        return "Cancelled. Nothing was saved to Neon."
    text = f"The upload stopped, and nothing was saved to Neon.\n{message}"
    if "size limit" in message or "No space left" in message:
        text += f"\n{NEON_FULL_HINT}"
    return text


def label(text, role=None):
    widget = QLabel(text)
    widget.setTextFormat(Qt.PlainText)
    widget.setWordWrap(True)
    if role:
        widget.setProperty("role", role)
    return widget

    def browse(self):
        start = self.path.text().strip() or common.TIFF_DIR
        path, _ = QFileDialog.getOpenFileName(self, "Choose a map (GeoTIFF)", start,

        """What stops the upload - only for the fields filled in so far."""
        if self.path.text().strip() and self.tiff_problem:
            return self.tiff_problem
        if self.name.text().strip():
            return name_problem(self.name.text(), self.existing)
        return ""

        problem = self.problem_text()
        self.problem.setText(problem)
        filled = bool(self.path.text().strip() and self.name.text().strip())
        self.upload_btn.setEnabled(self.job is None and filled and not self.tiff_problem and not problem)

    def set_busy(self, busy):
        for widget in (self.path, self.browse_btn, self.name, self.copy_box):
            widget.setEnabled(not busy)
        self.bar.setVisible(busy)
        self.bar.setValue(0)
        self.cancel_btn.setText("Cancel upload" if busy else "Cancel")

    def start(self):
        self.validate()
        if not self.upload_btn.isEnabled():
            return
        if getattr(self.w.compare, "job", None) is not None:  # a benchmark would hold Neon for minutes
            self.w.worker.cancel()
        self.set_busy(True)
        self.upload_btn.setEnabled(False)
        self.problem.setText("")
        self.status.setText("Waiting for Neon…")
        self.started = self.cancel_asked = False
        self.job = self.w.run_job("upload", "upload_map", self.path.text().strip(), self.name.text().strip(),
                                  keep_copy=self.copy_box.isChecked(),
                                  done=self.finished, failed=self.failed, progress=self.progress)

    def progress(self, done, total, text):
        self.started = True
        if self.cancel_asked:  # Cancel was pressed before the upload had begun
            self.w.worker.cancel()
        self.bar.setRange(0, max(total, 1))
        self.bar.setValue(done)
        self.status.setText(text)

    def finished(self, result):
        self.job = None
        self.uploaded = result
        self.accept()

    def failed(self, message):
        self.job = None
        self.set_busy(False)
        self.status.setText("")
        self.validate()
        self.problem.setText(upload_error_text(message))
        return True

    def reject(self):
        if self.job is None:
            super().reject()
            return
        self.cancel_asked = True  # the dialog stays until the worker has stopped
        self.status.setText("Cancelling…")
        if self.started:
            self.w.worker.cancel()

class MapsController:
    """The Map dropdown and the Maps menu: decides which map is shown, and switches maps."""

    def __init__(self, window, preferred=None, settings=None):
        self.w = window
        self.preferred = preferred        # --map NAME (start-up only)
        self.settings = settings if settings is not None else QSettings("HackNHire", "EUDR farm checker")
        self.maps = []                    # from NeonService.list_maps
        self.current = None               # the map shown, or being loaded
        self.farms = {}                   # map name -> the farms drawn on it (while the app is open)

        self.combo = QComboBox()
        self.combo.setMinimumWidth(170)
        self.combo.setEnabled(False)
        self.combo.setToolTip("The map in Neon that is shown, and that farms are checked against")
        self.combo.activated.connect(self.chosen)  # the user's choices only
        self.upload_act = window.action("Upload map…", slot=self.upload)
        self.delete_act = window.action("Delete map…", slot=self.delete)
        self.delete_act.setEnabled(False)
        self.refresh_act = window.action("Refresh list", slot=self.refresh)
        menu = QMenu(window)
        menu.addAction(self.upload_act)
        menu.addAction(self.delete_act)
        menu.addSeparator()
        menu.addAction(self.refresh_act)
        button = QToolButton()
        button.setText("Maps")
        button.setToolTip("Upload, delete or refresh the maps stored in Neon")
        button.setMenu(menu)
        button.setPopupMode(QToolButton.InstantPopup)
        window.insert_tools(window.draw_act, [QLabel("Map"), self.combo, button, None])
        window.listen("map_loaded", self.on_loaded)
        self.start()

    def names(self):
        return [m["name"] for m in self.maps]

    # ----- listing -----
    def start(self, select=None):
        """List the maps in Neon, then show one: select, else --map, else the last used, else the first."""
        if self.w.map_info is None and self.current is None:
            self.w.eudr.show_banner("Looking for maps in Neon…")
        self.w.run_job("maps", "list_maps", coalesce=True,
                       done=lambda found: self.listed(found, select), failed=self.list_failed)

    def refresh(self):
        self.start(select=self.current)

    def listed(self, found, select=None):
        self.maps = list(found)
        names = self.names()
        self.combo.blockSignals(True)
        self.combo.clear()
        for info in self.maps:
            self.combo.addItem(map_label(info), info["name"])
            self.combo.setItemData(self.combo.count() - 1, map_tooltip(info), Qt.ToolTipRole)
        self.combo.blockSignals(False)
        self.combo.setEnabled(bool(names))
        self.delete_act.setEnabled(bool(names))
        if self.preferred and self.preferred not in names:
            self.w.statusBar().showMessage(f"There's no map called '{self.preferred}' in Neon.", 8000)
        name = choose_map(names, select, self.preferred, self.settings.value("map", "", type=str))
        self.preferred = None
        if name is None:
            self.current = None
            self.w.eudr.clear("No maps in Neon yet. Upload a TIFF to get started.",
                              button="Upload map…", action=self.upload)
            return
        self.sync_combo(name)
        if name != self.current:
            self.switch_to(name)

    def list_failed(self, message):
        if self.w.map_info is None:
            self.w.eudr.show_banner(f"Could not list the maps in Neon. {message}", error=True, action=self.start)
        else:
            self.w.statusBar().showMessage(f"Could not list the maps in Neon: {message.splitlines()[0]}", 8000)
        return True

    def sync_combo(self, name):
        index = self.combo.findData(name)
        if index >= 0:
            self.combo.setCurrentIndex(index)

    # ----- switching -----
    def chosen(self, index):
        self.switch_to(self.combo.itemData(index))

    def switch_to(self, name):
        """Show another map: keep this map's farms, clear its results, load the new one."""
        if name is None or name == self.current:
            return
        old = self.current
        if old is not None:
            features = self.w.geojson["features"]
            if features:
                self.farms[old] = features
            else:
                self.farms.pop(old, None)
        self.current = name
        self.sync_combo(name)
        self.w.map_info = None
        self.w.emit("map_switching", old, name)
        if old is not None:
            self.w.js("clearAll()")
        self.w.eudr.load(name)

    def on_loaded(self, info):
        name = info["map_version"]
        if name != self.current:  # an earlier choice finishing late: the latest one follows
            return
        self.settings.setValue("map", name)
        features = self.farms.pop(name, None)
        if features:
            self.w.map.call("addFeatures", {"type": "FeatureCollection", "features": features})

    # ----- upload and delete -----
    def upload(self):
        dialog = UploadDialog(self.w, [(m["name"], m["schema"]) for m in self.maps])
        if dialog.exec_() == QDialog.Accepted and dialog.uploaded:
            name, note = dialog.uploaded["name"], dialog.uploaded.get("copy")
            self.w.statusBar().showMessage(f"Uploaded '{name}' to Neon." + (f" {note}" if note else ""), 10000)
            self.start(select=name)

    def delete(self):
        if not self.maps:
            return
        dialog = DeleteDialog(self.w, self.names(), self.current)
        if dialog.exec_() != QDialog.Accepted or not dialog.deleted:
            return
        name = dialog.deleted["name"]
        self.farms.pop(name, None)
        self.w.statusBar().showMessage(f"Deleted '{name}' from Neon.", 8000)
        if name == self.current:  # it was on screen: its farms and results go with it
            self.current = None
            self.w.map_info = None
            self.w.emit("map_switching", name, None)
            self.w.js("clearAll()")
            self.w.eudr.clear(f"Deleted '{name}'. Loading another map…")
        self.start()

**Files:**

**Interfaces:**

- [ ] **Step 1: Create `frontend/smoke_maps.py`** with this content:

```python
"""smoke_maps.py - an end-to-end check of several maps in Neon.

WRITES to Neon, but only to a throwaway map ('zz smoke test'), which it deletes again even if a step
fails. Your own maps are only listed (before and after, to show they are untouched).

    .venv\\Scripts\\python smoke_maps.py [--keep]        (from frontend\\)

1. Makes a small made-up TIFF in a temporary folder (in Java, far from any real map) with every
   class, including a no-data corner.
2. Uploads it with both approaches (one transaction), lists it, and opens it: every pixel the app
   rebuilds from Neon must match the TIFF.
3. Checks a point on every class and 30 made-up outlines with both approaches, and with the TIFF
   (stencils against its pixel rule, outlines against its exact areas).
4. Rebuilds the whole map from each approach (backend verify): 0 differing pixels.
5. Starts a second upload and cancels it: nothing may be left behind.
6. Deletes the test map, and checks that it is gone (skipped with --keep, e.g. for screenshots;
   delete it later with: python ..\\backend\\database\\maps.py delete "zz smoke test" --yes).
Exits with code 1 if anything doesn't match.
"""

import argparse
import os
import sys
import tempfile
import threading

import numpy as np
import rasterio
from rasterio.transform import from_origin

import farmgen
import neon_service
from backend import common, polygon_approach, stencil_approach
from legend import CLASS_LABELS

NAME, CANCEL_NAME = "zz smoke test", "zz smoke cancel"
X0, Y0, PIXEL = 110.0, -7.0, 1 / 12000   # Central Java: far from the real maps
WIDTH, HEIGHT = 700, 600


def made_up_map(seed=2026):
    """Class codes with every class present: forest blobs with deforestation inside them, a river,
    some 'needs review', and a no-data corner (255, which is read as class 5)."""
    rng = np.random.default_rng(seed)
    yy, xx = np.mgrid[0:HEIGHT, 0:WIDTH]
    data = np.zeros((HEIGHT, WIDTH), np.uint8)
    for _ in range(14):
        cy, cx, r = rng.integers(0, HEIGHT), rng.integers(0, WIDTH), rng.integers(25, 90)
        data[(yy - cy) ** 2 + (xx - cx) ** 2 < r * r] = common.FOREST
    for _ in range(10):
        cy, cx, r = rng.integers(0, HEIGHT), rng.integers(0, WIDTH), rng.integers(5, 25)
        data[((yy - cy) ** 2 + (xx - cx) ** 2 < r * r) & (data == common.FOREST)] = common.DEFORESTATION
    for _ in range(6):
        cy, cx, r = rng.integers(0, HEIGHT), rng.integers(0, WIDTH), rng.integers(5, 20)
        data[(yy - cy) ** 2 + (xx - cx) ** 2 < r * r] = common.REVIEW
    data[np.abs(yy - (HEIGHT / 2 + 60 * np.sin(xx / 70))) < 6] = common.WATER
    data[:40, :50] = 255
    return data


def write_tiff(path, data):
    with rasterio.open(path, "w", driver="GTiff", width=data.shape[1], height=data.shape[0], count=1,
                       dtype="uint8", crs="EPSG:4326", transform=from_origin(X0, Y0, PIXEL, PIXEL),
                       nodata=255) as dst:
        dst.write(data, 1)
    return path


def points_on_every_class(service):
    """A point in the middle of each class's pixels, and the class it must get."""
    grid, classes = service.grid, service.classes
    features, expected = [], {}
    for code in np.unique(classes):
        rows, cols = np.nonzero(classes == code)
        pick = len(rows) // 2
        x, y = grid.pixel_centre(int(rows[pick]), int(cols[pick]))
        key = len(features) + 1
        expected[key] = int(code)
        features.append({"type": "Feature", "properties": {"id": key, "name": f"{CLASS_LABELS[int(code)]} point"},
                         "geometry": {"type": "Point", "coordinates": [float(x), float(y)]}})
    return features, expected


def schema_exists(service, schema):
    def ask(conn):
        with conn.cursor() as cur:
            cur.execute("SELECT to_regnamespace(%s) IS NOT NULL", (schema,))
            return cur.fetchone()[0]
    return service._run(ask)


def main():
    ap = argparse.ArgumentParser(description="End-to-end check of several maps in Neon (writes a throwaway map).")
    ap.add_argument("--keep", action="store_true", help="leave the test map in Neon (e.g. for screenshots)")
    args = ap.parse_args()
    service = neon_service.NeonService(on_status=lambda text: print(" ", text.replace("…", "...")))
    problems = []

    def expect(ok, what):
        print(f"  {'OK ' if ok else 'BAD'} {what}")
        if not ok:
            problems.append(what)

    def names():
        return [m["name"] for m in service.list_maps()]

    before = {m["name"]: m for m in service.list_maps()}
    for leftover in (NAME, CANCEL_NAME):  # from an earlier run that was stopped
        if leftover in before:
            service.delete_map(leftover)
            before.pop(leftover)
    print("Your maps:", ", ".join(before) or "none")

    with tempfile.TemporaryDirectory() as tmp:
        data = made_up_map()
        tif = write_tiff(os.path.join(tmp, "smoke_map.tif"), data)
        try:
            print(f"\n1. Uploading a made-up {WIDTH} x {HEIGHT} map as '{NAME}'...")
            shown = set()

            def progress(done, total, text):
                step = text.split(" · ")[0]
                if step not in shown:
                    shown.add(step)
                    print("   ", text.replace("·", "-"))
            result = service.upload_map(tif, NAME, keep_copy=False, progress=progress)
            listed = {m["name"]: m for m in service.list_maps()}
            entry = listed.get(NAME)
            expect(result["name"] == NAME and entry is not None and entry["stencils"] and entry["outlines"],
                   "listed, with both approaches built")

            print("\n2. Opening it from Neon...")
            info = service.open_map(NAME)
            expect(info["map_version"] == NAME and info["schema"] == common.map_schema(NAME),
                   f"opened from schema {info['schema']}")
            expect(np.array_equal(service.classes, common.normalise(data)),
                   "every pixel rebuilt from Neon matches the TIFF")

            print("\n3. Checking farms with both approaches, and with the TIFF...")
            service.tif_path = tif
            features, expected = points_on_every_class(service)
            outlines = farmgen.make_features(neon_service.map_extent(service.grid), 0, 30, seed=7)
            for i, f in enumerate(outlines):
                f["properties"]["id"] = 100 + i
            out = service.check(features + outlines, explain=False)
            for row in out["rows"]:
                if row["kind"] == "point":
                    got = {row["results"][m]["point_colour"] for m in ("stencils", "polygons", "tiff_pixel")}
                    expect(got == {expected[row["key"]]}, f"{row['name']}: {CLASS_LABELS[expected[row['key']]]}")
            shapes = [r for r in out["rows"] if r["kind"] == "outline"]
            expect(all(r["agree"]["stencils_tiff"] for r in shapes),
                   f"stencils match the TIFF (pixel rule) on all {len(shapes)} outlines")
            expect(all(r["agree"]["polygons_tiff"] for r in shapes),
                   f"outlines match the TIFF (exact areas) on all {len(shapes)} outlines")
            expect(out["map"] == NAME, "the results say which map they were checked against")

            print("\n4. Rebuilding the map from each approach (verify)...")
            for label, module in (("stencils", stencil_approach), ("outlines", polygon_approach)):
                stats = service._run(lambda conn: module.verify(conn, service.grid, tif))
                expect(stats["mismatched"] == 0,
                       f"{label}: {stats['mismatched']:,} of {stats['pixels']:,} pixels differ")

            print("\n5. Cancelling an upload part-way...")
            other = write_tiff(os.path.join(tmp, "cancel_map.tif"), np.flipud(data).copy())
            cancel = threading.Event()
            try:
                service.upload_map(other, CANCEL_NAME, keep_copy=False,
                                   progress=lambda done, total, text: cancel.set(), cancel=cancel)
                expect(False, "the cancelled upload stopped")
            except neon_service.Cancelled:
                expect(True, "the cancelled upload stopped")
            expect(CANCEL_NAME not in names(), "nothing of the cancelled upload is listed")
            expect(not schema_exists(service, common.map_schema(CANCEL_NAME)), "and no schema was left behind")
        finally:
            if args.keep:
                print(f"\n6. Keeping '{NAME}' (--keep).")
            else:
                print(f"\n6. Deleting '{NAME}'...")
                if NAME in names():
                    service.delete_map(NAME)
                expect(NAME not in names(), "deleted from the list of maps")
                expect(not schema_exists(service, common.map_schema(NAME)), "its schema is gone")

    after = {m["name"]: m for m in service.list_maps() if m["name"] != NAME}
    expect(after == before, "your other maps are untouched")
    service.close()
    if problems:
        print(f"\n{len(problems)} problem(s).")
        return 1
    print("\nEverything matches.")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
